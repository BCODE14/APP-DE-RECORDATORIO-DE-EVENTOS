
# APP-DE-RECORDATORIO-DE-EVENTOS

Actualmente estoy desarrollando una aplicación de recordatorio de eventos que se integra con la API REST previamente construida.
La app permite al usuario registrar notas con fecha y hora de un evento, y además cuenta con un sistema de notificaciones automáticas que avisan en dos momentos clave:

Un día antes del evento.

En la misma hora en que se desarrolla el evento.

Funcionalidades principales 🚀

Crear eventos con título, fecha, hora y descripción.

Editar eventos ya registrados en caso de cambios.

Eliminar eventos de forma sencilla.

Notificaciones programadas que ayudan al usuario a no olvidar sus compromisos.

Beneficios

Mejora la organización personal y gestión del tiempo.

Brinda una experiencia intuitiva y práctica.

Se integra con la API REST, lo que garantiza escalabilidad y facilidad de mantenimiento.
